# 久未潜水 · 潜前复习

给很久没潜水的水肺潜水员做的两个小网页，用来回顾一次潜水从出发前到入水的流程。纯 HTML，单文件，不需要安装任何东西，手机和电脑浏览器都能打开。

## 内容

| 文件 | 说明 |
| --- | --- |
| `index.html` | 游戏版：5 幕，点画面上的东西完成出发前、上船、装备组装、同伴检查、入水 |
| `cards.html` | 卡片版：9 个阶段的一屏一步复习卡，可勾选，含久未潜水专区、手势速查、自测闪卡 |

### 游戏版流程

1. 出发前：把潜水证、logbook、面镜、脚蹼、电脑表、湿衣、手电筒放进包里，点小人的头做身体自查，点手机看浪况、能见度和天气
2. 上船：气瓶放气瓶架，脚蹼放脚蹼区，面镜、电脑表、手电筒和配重放进小篮子，然后听潜前简报
3. 装备组装：固定气瓶，接调节器，开气阀回半圈，看压力表，试二级头和低压充气管
4. 同伴检查：面对面检查 BWRAF
5. 入水：跨步入水，给 BCD 适量充气，保持正浮力，等同伴集合

## 使用

- 本地：直接用浏览器打开 `index.html` 或 `cards.html`
- 手机：建议用 Chrome 或系统自带浏览器

### 用 GitHub Pages 发布

1. 把本文件夹的内容上传到一个 GitHub 仓库
2. 进入仓库的 Settings，找到 Pages
3. Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存
4. 等一两分钟，就可以通过 `https://你的用户名.github.io/仓库名/` 访问游戏版，卡片版是后面加 `cards.html`

## 说明

- 内容按开放水域（PADI/SSI）的通用流程编写，不涉及技术潜水和减压潜水
- 其中的数字（气量、上升速度、安全停留、潜后飞行间隔等）仅作参考，请以你的潜水证机构和潜店的要求为准
- 游戏中的浪况、能见度和天气是示例数据
